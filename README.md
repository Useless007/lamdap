# Lamdap

A keyboard-first, local-first issue tracker for small teams, built around a hand-written sync engine.

"Lamdap" (ลำดับ) is Thai for "order": the server puts every change in order, and every client converges on it.

**Status:** early development. The project is in its foundation milestone (M0) and nothing is usable yet.
